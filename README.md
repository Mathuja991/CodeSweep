# CodeSweep Website

This directory now contains a standalone Next.js + Tailwind CSS showcase site for the CodeSweep project.

## Run locally

```powershell
cd website
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for production

```powershell
cd website
npm run build
npm run start
```

## Deployment

Set the Vercel project root to `website`. Vercel should auto-detect the app as a Next.js project.

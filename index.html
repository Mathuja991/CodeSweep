Project title

Agent-Based System for Centralised Files Deletion in Computer Labs

This system helps administrators safely remove student source-code files from lab computers before practical exams, using centralised scan-task dispatch, quarantine-first handling, and administrator verification before permanent deletion.

Project abstract

Problem Addressed and Solution Approach

Problem addressed

Computer labs must remove student-generated source files before practical exams to prevent unfair access to prior solutions.
Exams run at different times while other sessions continue, so only selected language files should be removed per exam context.
Manual cleanup across many machines is time-consuming, inconsistent, and prone to human error.

Approach

A master server dispatches structured scan tasks to client agents running on lab machines.
Agents scan selected directories, detect target-language files, and move matches into quarantine first.
Administrators review detected files on the dashboard and approve/reject deletion actions.
Only approved files are permanently deleted, and results are recorded for monitoring and audit trails.

System architecture

Master-agent design with verification-first deletion control.

The architecture combines a Flask admin interface, TCP master backend, distributed agents, and shared persistence to support controlled and auditable laboratory cleanup workflows.

Safety model

Files are quarantined first instead of immediate deletion.
Admins verify and approve deletion candidates manually.
Actions are tracked through status updates and audit logs.

Outcomes

Features

Automated laboratory preparation: Rapidly prepares labs for practical exams by detecting and removing specified source-code files.
Reduced administrative workload: Removes manual multi-machine cleanup and lowers human-error risk.
Safe and controlled deletion: Quarantine and verification gates prevent accidental destructive actions.
Centralised monitoring and control: Dashboard shows detected files from all agents and supports approve/modify/reject actions.
Cross-platform scalability: Supports distributed operation across Windows and Linux lab environments.
